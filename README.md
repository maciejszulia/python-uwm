# python-uwm

Python coursework: functions and modules, files, classes, NumPy, pandas. 33 commits.

University coursework from my Computer Science studies at UWM (2020–2024). I wrote the code by hand; the commit history is unchanged. This README was added in November 2026.

Years of work: 2021 (first commit on 23 February 2021, last commit on 30 May 2021).

## Contents

- `praca-domowa-1-wstęp/`, `praca-domowa-2-wstęp2/`: introductory tasks.
- `praca-domowa-3-funkcje+moduły/`: functions and the `moduly` package.
- `praca-domowa-4-operacje-na-plikach/`: file operations.
- `praca-domowa-5-classes/`: classes (clothing items).
- `praca-domowa-6-numpy1/`, `praca-domowa-7-numpy2/`: NumPy.
- `praca-domowa-8-pandas1/`, `praca-domowa-9-pandas2/`: pandas on CSV and Excel files; `IMPORT.md` lists the imports.

## Running

```
cd praca-domowa-6-numpy1 && python3 main.py
```

Result on 26 November 2026 (Python 3.14, NumPy 2.5): the script prints NumPy arrays; the last row is `[ 6765 10946 17711 28657 46368]`. NumPy 2.5 also prints a `RuntimeWarning` about an invalid value. Homework 8 and 9 need pandas, which this machine does not have, so I did not run them.
